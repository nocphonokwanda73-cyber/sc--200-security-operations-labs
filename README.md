# SC-200 Security Operations Labs

Hands-on labs for the Microsoft SC-200 Security Operations Analyst certification, covering Microsoft Defender XDR, Microsoft Purview, Microsoft Sentinel, and KQL.

All labs were completed in a training environment with a fictional company. Tenant IDs, account names, and credentials are covered or left out of the screenshots.

## Labs

- [Lab 1: Explore Microsoft Defender XDR](lab-01-path-1-xdr.md)
- [Lab 2: Explore Microsoft Purview Audit Logs](lab02-purview-audit-logs.md)

## Skills shown

- Applying Standard and Strict preset email protection policies
- Setting up a Microsoft Defender XDR workspace
- Checking and verifying audit logging with PowerShell
- Documenting security work clearly, with evidence
